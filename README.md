# Lay.ai
Lay.ai adalah platform LMS berbasis kecerdasan buatan di lay.psti.undiknas.ac.id yang memberikan "lapisan" interaktif di atas materi kuliah. Dosen mengunggah PDF, dan Lay.ai mengubahnya menjadi knowledge base yang bisa diajak bicara. Mahasiswa dapat bertanya dan berdiskusi dengan asisten AI untuk memperdalam pemahaman mereka secara mandiri.
